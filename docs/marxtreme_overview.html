输入与时间控制

  • var / time / time_dim="time"：指定变量与时间轴
  • squeeze_singleton="zlev"：去除 OISST 单长度深度维
  • freq="daily"|"monthly"：日尺度或月尺度 (Jacox 2020)
  • calendar：自动识别公历与 360_day/noleap/all_leap
  • detect_period=(start, end)：限定检测时段子集

事件、窗口与物理守卫

  • event="high"|"low"|"both"（别名 mhw/mcs）
  • pctile_high=0.90 / pctile_low=0.10（支持 0–1 或 0–100）
  • window_half_width=5 · smooth_width=31 · min_duration=5 · max_gap=2
  • max_pad_length=0：仅检测期短缺测插值，不污染气候态
  • min_valid_fraction（海冰守卫）· lower_bound + bound_policy

输出项与精度性能

  • return_clim · return_intensity_ts · return_daily_category_ts
  • return_event_category_ts=False：对齐 m_mhw 事件峰值分级
  • working_dtype="auto"：自动启用 f32 紧致 Rust 快路径
  • intensity_dtype="float64"|"float32"：减半磁盘与内存
  • memory_limit="4GB"：自动空间/深度分块控内存

严格单文件落盘

  • out="run.nc"：按后缀自动识别格式，只写 1 个文件
  • out_format：显式覆盖格式（不依赖扩展名）
  • mat_layout="v73"|"detectc"：v7.3 无上限或 v5 细胞数组
  • 事后导出：res.save(path) / res.to_mat(path, layout)
  • 单文件重开：mx.open(path) / EventCatalog.open(path)

最小可运行示例
单文件落盘 · O(1) 查格点 · 一键转 MATLAB 
import marxtreme as mx

res = mx.detect(
    "OISST_1982_2025_r360x180.nc", var="sst", squeeze_singleton="zlev",
    event="both",                                              # 单遍检 MHW + MCS
    baseline=mx.MovingBaseline(window_years=31, center=True),  # 或 Fixed / Detrended
    lower_bound=-1.8, bound_policy="flag",
    intensity_dtype="float32", memory_limit="8GB",
    out="outputs/oisst_mhw.nc",                                # 严格单文件 (.nc / .mat / .npz / .parquet / .csv)
)

df_pt = res.events.sel(lat=-42.5, lon=148.0)                   # O(1) 单格点查表 (懒切片)
cnt   = res.events.count_map()                                 # 零扫表空间事件数分布
res.to_mat("outputs/oisst_detectc.mat", layout="detectc")      # 单文件 MATLAB v5 / v7.3
res2  = mx.open("outputs/oisst_mhw.nc")                        # 单文件直接重开
